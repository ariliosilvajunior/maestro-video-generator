# Guia de partida: Reel Lab, The Craft

Referência oficial do dono (03/11/2026): "esta página tem muita coisa para aprendermos a fazer matérias
profissionais... sempre recorra a ela para iniciarmos algo".

Fonte: https://reel-lab.com/craft/ (acesso liberado na rede desta sessão). É um guia de prompts para imagem e vídeo
feito com o Nano Banana, o mesmo modelo de imagem do Flow.

**Quando usar:** antes de começar QUALQUER material visual, seja episódio, Kit, propaganda, carrossel com imagem ou
Reels. Leia a parte que vale para aquele trabalho e aplique. Abaixo está o resumo em português. Para os exemplos com
imagem, abra o link da seção.

| Parte | Link | O que levar para o trabalho |
|---|---|---|
| 00 Comece aqui | [#start](https://reel-lab.com/craft/#start) | Uma mudança por geração e o resto idêntico. Vídeo custa cerca de 30× a imagem: acerte a imagem primeiro. |
| 01 Ótica | [#optics](https://reel-lab.com/craft/#optics) | A lente define onde a câmera está e o formato do rosto. Número só funciona com a consequência dele. Foco é dizer o que importa no quadro. Grão leve é o anti-IA mais barato. |
| 02 Luz | [#light](https://reel-lab.com/craft/#light) | Diga a fonte e o lado. O drama vem de tirar luz de preenchimento, não de pôr mais luz. A hora azul iguala céu e lâmpada. Fumaça ou poeira dão profundidade. Contraste também é quente contra frio. |
| 03 O quadro | [#frame](https://reel-lab.com/craft/#frame) | Diga onde a pessoa fica, senão ela cai no meio. Nitidez vai no que a cena conta. Campo deixado vazio vira a média da internet. Use nomes e física, não adjetivos. |
| 04 O visual | [#look](https://reel-lab.com/craft/#look) | A cor só redistribui a luz que existe. Imagem perfeita demais denuncia a IA. Descreva a física do meio (pincelada, retícula), não "no estilo de". |
| 05 Bonito | [#beautiful](https://reel-lab.com/craft/#beautiful) | Escreva o bloco de visual antes da 1ª cena e não renegocie depois. Escolha o registro primeiro. Sombra de pele não pode ficar cinza. |
| 06 Combinações | [#advanced](https://reel-lab.com/craft/#advanced) | As palavras caras entram uma vez, e por cena só muda o que o público notaria. Se não dá para escrever a "assinatura" da cena numa frase, ela não está pronta. |
| 07 Objetos | [#objects](https://reel-lab.com/craft/#objects) | O brilho tem o formato da fonte de luz. Fundo liso vende o objeto; o objeto no lugar vende a vida em volta. |
| 08 Consistência | [#consistency](https://reel-lab.com/craft/#consistency) | Folha com 3 vistas (corpo de frente, perfil, rosto). Descreva o personagem uma vez e depois só a cena. O que se repete entre cenas precisa de plano fixo. |
| 09 Vídeo | [#video](https://reel-lab.com/craft/#video) · [#scene](https://reel-lab.com/craft/#scene) · [#moves](https://reel-lab.com/craft/#moves) | Quadro inicial = onde começa; referência = o que não pode mudar. No máximo 3 pessoas descritas, quem sai do quadro sumiu, sem espelho, lados ditos de novo após o corte, emoção em corpo, sem letreiro. Diga se a câmera se move ou só a lente (pan ≠ travelling, zoom ≠ aproximar). Gere de novo antes de reescrever. Vídeo pede frase curta sobre o que se mexe. Frases exatas dos 20 movimentos: `docs/MOVIMENTOS_CAMERA.md`. |
| 10 O processo | [#pipeline](https://reel-lab.com/craft/#pipeline) | Ordem: projeto → cena → plano → tentativa. Refaça tentativas, não cenas. 6 quadros que se encaixam valem mais que 20 soltos. 80% entregue vale mais que 95% abandonado. |
| 10b A ordem | [#order](https://reel-lab.com/craft/#order) | 7 passos: história → visual → Kit → explorar 3×3 → imagens → movimento → finalização. O app Reel Lab (pago, US$ 49, roda no Claude Code com chaves fal/Higgsfield, não usa o Flow) não foi comprado — usamos só o método (dono, 03/11). |
| 11 Bancada | [#bench](https://reel-lab.com/craft/#bench) | Montador de prompt, catálogo de termos, cola e vídeos do processo completo. |
