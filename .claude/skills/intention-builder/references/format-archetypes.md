# Format archetypes

Read the matching archetype as soon as the format is known. Each one pre-fills
runtime, aspect, cut budget, camera mode, coverage expectations and deliverables
— which removes five or six questions from the tree before round one, and lets
you *confirm* rather than *ask*.

Everything here is a default to be overturned, not a rule. State the default,
say what it costs, let the user move it.

## 30-second ad

| | |
|---|---|
| **Runtime** | 30s hard. Also cut 15s and 6s from the same material. |
| **Aspect** | 16:9 master, 9:16 and 1:1 derived — frame for all three from the start |
| **Cut budget** | 8-14 shots. Under 8 feels slow; over 14 and nothing registers. |
| **Camera mode** | M2 for product-led, M1 for story-led |
| **Structure** | Hook (0-3s) · problem or desire (3-12s) · product (12-22s) · payoff and logo (22-30s) |
| **Coverage** | One hero shot that carries the whole thing, plus 6-10 supports and a product beat |
| **Route** | LIVE-ACTION, or CINEMATIC-ACTION if there is dialogue |
| **Depth** | 11 questions, 2 rounds — ask: S2, S4, S7, E1, E5, W3, W4, CS1, L1, C2, C6. Everything else is derived and flagged. Product-led cut with nobody on screen: drop CS1 and C2 — nine. |

**What beginners forget:** the last three seconds. An ad ends on a logo or a
line, and if the doc does not lock that, the edit has nowhere to land. Also: the
first frame has to work as a still, because a third of the audience sees only
that.

**Deliverables:** 30s master · 15s · 6s bumper · 9:16 and 1:1 versions · a still
frame for paid placement · captions burned and clean.

## 15-second social cut

| | |
|---|---|
| **Runtime** | 15s, and it must work muted |
| **Aspect** | 9:16 native. Do not crop a 16:9 — reframe it. |
| **Cut budget** | 5-8 shots |
| **Camera mode** | M2 or M1, tight |
| **Structure** | Hook in the first 1.5s or it is over · one idea · one CTA |
| **Coverage** | No establishing shots. There is no room. |
| **Depth** | 6 questions, 1 round — ask: S2, S4, S7, E1, E5, C6. Everything else is derived and flagged. No look questions if this is cut from an existing master — it inherits L1. |

**What beginners forget:** it is watched with sound off, in a feed, at arm's
length. Anything smaller than a thumb on screen is invisible. Text is a design
element, not a caption.

**Deliverables:** 9:16 with burned captions · a clean version · a 1:1 fallback.

## Brand film (60-120s)

| | |
|---|---|
| **Runtime** | 60-120s. Ask which — the difference is roughly ten shots. |
| **Aspect** | 16:9 or 2.39:1 |
| **Cut budget** | 20-40 shots |
| **Camera mode** | M1 primary, M5 for establishing plates |
| **Structure** | A single idea, stated once at the top and once at the bottom, with a middle that earns it |
| **Coverage** | Location plates, people at work, hands and detail, one interview or VO spine |
| **Depth** | 18 questions, 3 rounds — ask: S2, S4, S5, S6, S7, S8, E1, E4, E5, W3, W4, W5, CS1, L1, C1, C2, C3, R1. Everything else is derived and flagged. |

**What beginners forget:** the VO. Brand films almost always end up with
narration, and if the doc has no script, the edit is built to a rhythm that then
has to be broken to fit the words. Lock the VO before the beats or mark the beats
provisional. There is no VO node on the live-action routes — MG7 SCRIPT STATE is
MOTION-only — so do not invent one: if no script exists, say so, write the beats
in this doc as provisional, and send them to `story-beats` next.

**Deliverables:** master · 30s cutdown · vertical · stills pull.

## Product hero

| | |
|---|---|
| **Runtime** | 15-45s, usually loops |
| **Aspect** | 16:9 and 1:1 |
| **Cut budget** | 6-12, or one continuous move |
| **Camera mode** | M2 Studio, always |
| **Look default** | `product-on-white`, `beverage-macro-cold`, or `coffee-commercial-warm` by category |
| **Structure** | Reveal · detail · function · full object |
| **Depth** | 7 questions, 1 round — ask: S2, S4, S7, W4, C6, L1, D3. Everything else is derived and flagged. No CS1 and no E1 — a product has no interiority and no narrative; the reveal order is the structure. |

**What beginners forget:** the product's real material behaviour. Chrome needs
something to reflect, matte plastic needs a rim, glass needs a background to
refract. "Shoot it on white" is a lighting problem, not a background choice.

**Deliverables:** hero loop · detail set · 1:1 · a transparent-background pass if
it goes into layouts.

## Music video

| | |
|---|---|
| **Runtime** | Track length. Get the actual duration to the second. |
| **Aspect** | 16:9, or 9:16 if it is a release-day social piece |
| **Cut budget** | Cuts land on the beat — get the BPM and derive |
| **Camera mode** | Mixed by section: M2 editorial, M3 action, M4 performance, M1 narrative |
| **Structure** | Performance spine plus one or two concept sequences |
| **Depth** | 16 questions, 3 rounds — ask: S2, S4, S6, S7, E1, E4, E5, W2, W3, W4, CS1, L1, C1, C2, C3, C4. Everything else is derived and flagged. Narrative spine: add P1, P2, P5, P7 — twenty, four rounds. |

**What beginners forget:** performance coverage is not optional. Even a concept
video needs the artist mouthing the words from at least three angles, or the edit
runs out of material at the second chorus. Also: each section is a different
camera mode, and each mode gets its own camera block — never averaged.

**Deliverables:** master · vertical loops for release · stills · a clean
performance-only cut as insurance.

## Short film

| | |
|---|---|
| **Runtime** | 5-15 min. Festival caps are often 15. |
| **Aspect** | 2.39:1 or 1.85:1 |
| **Cut budget** | Scene by scene, not global |
| **Camera mode** | M1, with M5 for transitions |
| **Route** | CINEMATIC-ACTION — this is where the acting-task layer earns its keep |
| **Depth** | 28 questions, 5 rounds — ask: S2, S3, S4, S5, S6, S7, E1, E2, E3, E4, E5, W1, W3, W4, W5, CS1, L1, L2, C1, C2, C3, C5, C6, P1, P2, P5, P7, R1. Everything else is derived and flagged. Then P3, P4, P6, the CINEMATIC-ACTION adders X1-X4, and one scene sweep per scene (question-tree.md's scene-sweep section — four nodes, not two). The only archetype here that goes per scene. |

**What beginners forget:** the ending. Almost every weak short has a strong
premise and no ending. Grill E1 harder here than anywhere else, and refuse to
proceed on "and then it just kind of stops."

**Deliverables:** festival master · trailer · poster still · dialogue list.

## Doc interview

| | |
|---|---|
| **Runtime** | Determined in the edit, not the shoot |
| **Aspect** | 16:9 master, 9:16 pull-outs |
| **Cut budget** | n/a — B-roll density is the real number: 40-60% of runtime |
| **Camera mode** | M1 for the interview, M5 for plates |
| **Look default** | `a24-flat-daylight` or `window-lookbook` for the interview setup |
| **Depth** | 10 questions, 2 rounds — ask: S2, S4, S7, S8, E1, W3, W4, CS1, C2, L1. Everything else is derived and flagged. No C3 — the subject arrives in what they arrive in; note it on the day. |

**What beginners forget:** the B-roll list. An interview without a shot list for
what plays over it becomes a talking head. Derive the B-roll list from the
questions, not after the shoot.

**Deliverables:** master · social pull-quotes · transcript · clean interview
audio.

## Doc vérité

| | |
|---|---|
| **Runtime** | Edit-determined |
| **Aspect** | 16:9 |
| **Camera mode** | M1, handheld throughout |
| **Look default** | `verite-handheld` |
| **Coverage** | Follow, do not stage. Two cameras if the budget allows. |
| **Depth** | 8 questions, 2 rounds — ask: S2, S4, S7, E1, E5, W3, W4, CS1. Everything else is derived and flagged. W3 and W4 together are the whole lighting plan here, so grill both. |

**What beginners forget:** you cannot light it, so you have to choose when and
where. The location and time of day *are* the lighting plan.

## Social vertical

| | |
|---|---|
| **Runtime** | 20-60s |
| **Aspect** | 9:16 native |
| **Cut budget** | A cut every 2-4 seconds |
| **Camera mode** | M1 handheld or M2 tight |
| **Structure** | Hook · payoff promised · content · payoff delivered |
| **Depth** | 7 questions, 1 round — ask: S2, S4, S7, E1, E5, W3, C6. Everything else is derived and flagged. |

**What beginners forget:** safe zones. The top and bottom sixth of the frame are
covered by platform UI. Anything important there is gone.

## Explainer (motion graphics)

| | |
|---|---|
| **Runtime** | 60s-20min |
| **Aspect** | 16:9, or 9:16 for shorts |
| **Route** | MOTION — motion-builder, or remotion-builder if exact text, charts or data must be right |
| **Structure** | VO is the timeline. Every beat maps to a visual. |
| **Coverage** | 35-45% talking head or screen recording · 35-45% generated · 10-20% loops and buffers |
| **Depth** | 10 questions, 2 rounds — ask: MG7 first, then S2, S4, S7, MG1, MG3, MG4, MG5, MG6, D3. Everything else is derived and flagged. No CS1 on this route — MOTION replaces Layer 4 and the node does not exist. No E1 either: the last line of the VO is the ending. |

**What beginners forget:** the script comes first. There is no such thing as
storyboarding an explainer before the VO exists — run `story-beats` and come back.
Also: one style family, never two.

**Deliverables:** master · clip library tagged by priority · the style sheet
itself, which is reusable across the whole series.

## Trailer / sizzle

| | |
|---|---|
| **Runtime** | 60-120s |
| **Cut budget** | 40-80 shots — the highest density of any format here |
| **Camera mode** | Inherited from the source material |
| **Structure** | Three acts compressed: setup (0-30%) · escalation (30-75%) · button (75-100%) |
| **Depth** | 9 questions, 2 rounds — ask: S2, S4, S6, S7, E1, E5, A5, B5, D3. Everything else is derived and flagged. No CS1 and no L1 — stance and look are inherited from the source material. |

**What beginners forget:** a trailer is a sound-design piece with pictures
attached. Lock the audio structure — the drops, the silences, the button — before
the picture beats.

## Fashion film

| | |
|---|---|
| **Runtime** | 30-90s |
| **Aspect** | 16:9 and 9:16, and often 4:5 for editorial feeds |
| **Cut budget** | 10-25 |
| **Camera mode** | M2 Studio / Editorial |
| **Look default** | `editorial-studio-void`, `hard-flash-editorial`, `window-lookbook` |
| **Depth** | 10 questions, 2 rounds — ask: S2, S4, S7, E5, W3, W4, CS1, L1, C2, C3. Everything else is derived and flagged. C3 is the subject, not an afterthought — walk the garment head to toe. Add E1 only if it actually tells a story; most fashion films end on a look, not an event. |

**What beginners forget:** the garment. Fabric behaviour — how it moves, catches
light, creases — is the subject, and it needs its own beats at 100mm. A fashion
film that never gets close to the cloth has not covered the product.

---

## Event film

| | |
|---|---|
| **Runtime** | 90s-5min highlight, plus a 60s social cut |
| **Camera mode** | M1, M4 for anything on a stage |
| **Coverage** | Arrivals, the ritual moment, reactions, details, the ending |
| **Depth** | 8 questions, 2 rounds — ask: S2, S4, S7, E1, E5, W3, W4, C1. Everything else is derived and flagged. Name the three must-have reactions inside E5 rather than adding a node. |

**What beginners forget:** the reaction shots. The event itself is easy; nobody
can re-shoot the face of someone watching it. Name the three reactions that must
be captured.

## Testimonial

| | |
|---|---|
| **Runtime** | 60-90s |
| **Aspect** | 16:9 plus 9:16 |
| **Camera mode** | M1, two sizes on one subject |
| **Structure** | Problem · what changed · the specific result · recommendation |
| **Depth** | 8 questions, 1 round — ask: S2, S4, S7, S8, E1, W3, W4, CS1. Everything else is derived and flagged. No C2 and no C3 — one person, one setup; there is nobody to tell them apart from. |

**What beginners forget:** the specific number. A testimonial without one
concrete detail is indistinguishable from every other testimonial. Lock the
detail in the doc so the interview goes after it.

## The universal traps

Regardless of format, check these before the doc is written:

1. **Cut budget vs runtime.** Below one second per shot nothing registers;
   above eight it reads as a slideshow. Between those, the number is editorial
   and the archetype's own cut budget wins. The one place to look twice is
   *generated* beats inside a single clip: a model given under about 2.5
   seconds to resolve a shot rarely does, so a CINEMATIC-ACTION scene with
   fourteen beats in thirty seconds is worth a sentence — while a
   fourteen-shot thirty-second ad, cut in an edit, is completely normal.
   Trailers, sizzles and bumpers are exempt outright: packing 60 shots into 90
   seconds is the format.
2. **The first frame.** Every format has a first frame that gets seen alone,
   as a thumbnail or a paused feed. Lock it deliberately.
3. **The last three seconds.** Where it lands. Almost never specified, almost
   always the problem in the edit.
4. **Muted playback.** If it plays in a feed, it plays silent first. Does it
   still work?
5. **The derived versions.** A 16:9 master that was never framed for 9:16 has
   to be re-shot or badly cropped. Decide at the doc, not at the edit.
6. **Depth.** Every archetype above carries a Depth row naming the nodes to ask.
   Ask those; derive the rest and flag them. The optional craft pass has its own
   gate in [camera-stance.md](camera-stance.md) Part 2 — that file is the only
   place the gate is stated, so do not restate it here.
7. **Who signs off.** If there is a client, the doc is the thing they approve.
   Write it so a non-filmmaker can read it, and put the jargon in the token
   sections at the back where it belongs.
