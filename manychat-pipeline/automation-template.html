Como aplicar no ManyChat
⚡ Método oficial: DUPLICAR o TEMPLATE. Abra o template-mestre ⭐ TEMPLATE — Auto-DM (Flow Builder, fica em DRAFT, nunca publica) → (id em config.json → manychat.template_flow_id) → More Actions (⋮) → Duplicate. Na cópia troque só (1) a keyword (única!), (2) a “DM com o link” (ramo Yes) e (3) o link → renomeie [<KEYWORD>] … → Set Live. Respostas públicas, DM de abertura, follow-gate e o botão “Estou Seguindo” já vêm prontos e idênticos. Use os campos acima pro texto novo.
Pra mudar a cópia de TODOS os próximos posts: edite o próprio template-mestre (vale só pros próximos).

Estrutura do template (Flow Builder): gatilho → DM de abertura (“Quero Receber”) → Condição: segue a conta? → Sim → DM com link (“Acessar agora”) · Não → follow-gate + “Estou Seguindo” (volta pra checagem).

Do zero, em easy-builder (fallback — atenção: o easy-builder NÃO permite o botão “Estou Seguindo”, mostra o sistema “Following” em inglês):

  1. Preflight: confirme que o canal Instagram do ManyChat (Settings → Instagram) é o MESMO em que o pipeline posta o Reel (config.json → posting.instagram_handle). Se não for, os comentários são perdidos silenciosamente.
  2. Automation → New Automation → template “Auto-DM links from comments” (easy_builder_cgt_next_post_multi_links).
  3. Post: selecione “any post or reel”.
  4. Comments: cole a keyword única; ative “reply to their comments under the post” e cole as 3 respostas públicas.
  5. Opening DM: mantenha ON; cole a mensagem de abertura + botão “Quero Receber”.
  6. Follow-gate: marque a caixa “a DM asking to follow you before they get the link” e cole a mensagem PT-BR (campo “4 Follow-gate” acima). Não existe botão de “já segui” no easy-builder — o ManyChat detecta o follow sozinho e libera o link; a mensagem ainda pede pra re-tocar no botão como garantia.
  7. Link DM: cole a mensagem com o link; Add a link → rótulo do botão + a URL → Save.
  8. Go Live → reabra e confira: keyword certa, follow-gate marcado, link certo, status LIVE.
  9. Renomear (OBRIGATÓRIO): na lista de Automations, kebab (⋮) da automação → Rename → [<KEYWORD>] Auto-DM links from comments → Rename. (Use o campo “0 Nome da automação” acima.)
  10. Registre no keyword-ledger.json via set_resource_cta.py (nunca edite o JSON à mão).
⚠️ Regra de ouro: a keyword tem que ser única. Como toda automação dispara em “any post or reel”, duas automações com a mesma keyword disparam as duas (uma keyword de teste duplicada já disparou duas automações). Sempre cheque a lista acima.
