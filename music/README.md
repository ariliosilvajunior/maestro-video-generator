# music/ — background tracks for Phase 9 (sound design)

Drop **at least one** royalty-free track here (`.mp3`, `.wav`, `.m4a`, `.aac`). `add_music.py`
lists this folder; the agent picks the track whose mood matches the creative brief
(`music_mood`), so name files by mood — e.g.

```
music/light-friendly-01.mp3
music/tense-suspense-01.mp3
music/epic-cinematic-01.mp3
music/elegant-ambient-01.mp3
```

No tracks ship with this package (music licensing is personal to your account). Good sources
of tracks you are allowed to use on Instagram/YouTube/TikTok:

- YouTube Audio Library (free, check the per-track attribution flag)
- Pixabay Music (free, Pixabay Content License)
- Uppbeat / Epidemic Sound / Artlist (subscription, cleared for social media)

Keep tracks around 1–3 minutes; the mixer starts the song after the hook riser and fades it
out over the last 3 seconds, at volume 0.07 relative to the narration.
